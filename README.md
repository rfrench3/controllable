
<h1>Controllable</h1>

<p>A QML module that provides support for controllers.</p>

<br>

<br>

<h1>Where to Install the Latest Release</h1>

The module is available in [Terra](https://docs.terrapkg.com/usage/installing/). Once the installation instructions are met, the package will be available as `qt6-controllable`.
```bash
sudo dnf install qt6-controllable
```

It is also posted to the github releases.
- https://github.com/rfrench3/controllable/releases

<br>

<h1>Developer Instructions</h1>

The project is developed using devcontainers. You can use `just` to see various scripts for packaging it.

An app showcasing various example implementations of the module is provided in the repository, and will be built and run using `just run`. 

A real-world example is available through [bazzite-updater](https://github.com/rfrench3/bazzite-updater).
